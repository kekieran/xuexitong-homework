# 用于学习通的作业助手

可以抓取作业并且可接入 AI 辅助，项目包含依赖可离线下载。技术有限，只是深职大的网页抓取。

## 功能

- 抓取并整理作业信息
- 查看作业截止时间和完成进度
- 接入 AI 辅助作答
- 支持选择题、填空题和简答题辅助
- 项目内包含依赖文件，可在无网络环境下安装
- 浏览器数据和作业数据保存在本机

## 启动

双击：

```text
启动学习通作业助手.cmd
```

启动脚本会自动准备项目环境并运行助手。
