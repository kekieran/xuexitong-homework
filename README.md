# 用于学习通的作业助手（多学校版）

可以抓取作业与实验报告并可接入 AI 辅助，项目包含依赖可离线安装。登录时仅需输入账号和密码，程序会自动识别所属学校站点并完成后台补登。

## 功能

- 自动识别学校超星站点并静默完成主站与学校站点登录（遇到滑块验证时自动唤起验证窗口）
- 抓取并整理作业及实验报告信息
- 查看作业截止时间和完成进度
- 接入 AI 辅助作答
- 支持选择题、填空题、简答题及实验报告辅助填写
- 项目内包含依赖文件，可在无网络环境下安装
- 浏览器数据和作业数据统一保存在本机 `data/` 目录

## 启动

双击：

```text
启动学习通作业助手.cmd
```

启动脚本会自动准备项目环境并运行助手。
